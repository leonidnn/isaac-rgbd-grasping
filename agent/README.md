# agent - обученный агент, чтоб попробовать самому

Тут всё, что нужно, чтоб запустить моего агента у себя на компе: веса и два файла кода. Остальной репозиторий не нужен.

Агент - Q-карта: смотрит сверху на карту высот стола и говорит, куда и под каким углом хватать. Сетей две:
- `qmap_depth.pt` - основная, училась 12 часов (28 тыс. попыток), берёт тетрапак и банку;
- `qmap_chips.pt` - училась с нуля 5 часов (6 400 попыток) только на уменьшенных чипсах 6x8.7x2 см (старый пакет 15x22 см не помещался в пальцы).

Какую сеть звать, решается по типу объекта: на чипсах вторая, на остальном первая. Итог в быстрой среде: чипсы 88%, тетрапак и банка по 95%. Как устроено и что получилось - в главном README.

## Скачать только нужное

```bash
git clone --filter=blob:none --no-checkout https://github.com/LeonidNN/isaac-rgbd-grasping.git grasp_agent
cd grasp_agent
git sparse-checkout set --no-cone agent assets/usd MetaIsaacGrasp/models/ur10e_with_hand_e_and_camera_mount.usd
git checkout main
```

Выйдет ~35 МБ: эта папка, модели трёх объектов и модель робота UR10e с захватом (последние две нужны только для симулятора).

## Вариант 1. Поставь объект сам (любой комп, без симулятора)

Нужны python 3.10+, torch, matplotlib: `pip install torch matplotlib`

```bash
python agent/agent.py                               # 6 готовых сцен
python agent/agent.py can 0.1 0.5                   # банка в точке x=0.1, y=0.5 (метры)
python agent/agent.py tetrapak-lying -0.1 0.45 30   # лежачий тетрапак, длинная сторона под 30 градусов
python agent/agent.py can 0.1 0.5 + chips 0 0.6 20  # несколько сцен через +
python agent/agent.py --old chips 0 0.6 20          # чипсы основной сетью, без дообучения
```

Объекты: `tetrapak` (стоит), `tetrapak-lying`, `can`, `chips` (уменьшенные), `chips-big` (старые большие, для сравнения). Координаты по столу: база робота в нуле, x вбок (от -0.3 до 0.3), y вперёд (от 0.35 до 0.75 нормально, ближе к роботу на снимке висит кисть). Угол - куда смотрит длинная сторона.

Скрипт сам рисует карту высот, какую увидела бы камера сверху, отдаёт сети и рисует `agent/out/put.png`:
- сверху карта высот (белое - высокое), красный крестик - куда агент хватает, палка через него - вдоль чего сойдутся пальцы, зелёная точка - центр объекта
- снизу тепловая карта - где сеть думает, что возьмёт (красное - уверена)

В консоль пишет, куда хватает, сколько см от центра, под каким углом пальцы к длинной стороне и какой шанс по сети. Например, лежачий тетрапак он берёт поперёк узкой стороны в паре мм от центра с шансом ~1.0, уменьшенные чипсы - в 1-2 см от центра с шансом ~0.97-1.0. С `--old` на тех же чипсах основная сеть уверена гораздо меньше (~0.1-0.2), хотя в симуляторе без дообучения всё равно берёт их в 42% случаев. На больших чипсах шанс везде ~0 - пакет шире, чем раскрываются пальцы, и сеть это выучила.

Физики тут нет - это то, что сеть думает. Возьмёт ли рука на самом деле - вариант 2.

## Вариант 2. В симуляторе

Нужны Isaac Sim 4.5 + Isaac Lab 2.0 (как ставить - у NVIDIA) и видюха с RT-ядрами (RTX). Я гонял на RTX 2080 Ti.

```bash
python agent/sim.py fast      # 8 столов разом, рука телепортом встаёт над точкой (так агент учился), пара минут
python agent/sim.py arm       # один стол, рука едет из домашней позы к объекту, ~30 с на эпизод
```

Опции: `--obj tetrapak can` (какие объекты), `--old` (чипсы тоже берёт основная сеть), `--n 20` (fast - раундов по 8 попыток, arm - эпизодов на объект), `--video 2` (сколько первых раундов/эпизодов писать в gif), `--seed 5` (другие раскладки).

Результаты - в `agent/out/<режим>_<время>/`: `log.txt` (SR по объектам с 95% интервалом Уилсона), `scenes.png` (как в варианте 1, только сцены настоящие), gif сбоку.

Что ожидать (мои цифры): в быстрой среде тетрапак ~93%, банка ~89% у одной основной сети и 95% / 95% на итоговой оценке варианта с двумя сетями, уменьшенные чипсы 88% (с `--old` - ~42%); на руке с моим планировщиком тетрапак 18/20, банка 19/20, чипсы на руке пока не проверял. Чипсы в `sim.py` уменьшенные (`assets/usd/chips_small`), в нём сам режим с двумя сетями я ещё не прогонял - цифры выше из своих скриптов оценки в `results/7_chips`. В `sim.py` подъезд руки попроще (IK по прямой, как у оракула в `results/4_env`), так что в режиме arm цифры могут немного отличаться.

## Что тут лежит

- `qmap_depth.pt` - веса основной сети (3 МБ)
- `qmap_chips.pt` - веса сети для уменьшенных чипсов (3 МБ)
- `agent.py` - сеть, как она выбирает схват, картинки, вариант 1
- `sim.py` - всё для Isaac Sim (сцена, рука, среда), вариант 2. Собран в один файл из моих файлов репозитория, откуда что - написано в начале
